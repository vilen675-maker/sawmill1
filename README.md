# Sawmill PWA — iPhone

PWA-прототип: калькулятор, карта раскроя, цикл распиловки с поворотом бревна в градусах, вторичные доски и обрезки, заказы.

## Публикация с iPhone
1. Открой https://github.com в Safari и создай репозиторий `sawmill` (Public).
2. Add file → Upload files, загрузи все файлы этой папки, Commit changes.
3. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
4. Открой опубликованную ссылку в Safari → Поделиться → На экран Домой.

## Ограничения
Это не нативный IPA. Схема распиловки — упрощённая демонстрация, не производственный оптимизатор. Перед использованием на станке обязательно проверь геометрию, углы, обзол, конусность, пропил, фиксацию и ограничения оборудования.
